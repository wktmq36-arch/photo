# Photo

Windows용 그림 정리·모자이크 앱. Python + PySide6 + Pillow.

## 실행
배포 ZIP을 모두 풀고 `Photo/Photo.exe`를 실행합니다. `_internal` 폴더도 함께 있어야 합니다.

## 사용
1. WebP, PNG, JPEG 등의 파일 또는 폴더를 창에 드롭합니다. 폴더는 하위 폴더까지 읽습니다.
2. 썸네일 클릭으로 미리보기를 보고, 썸네일 자체를 드래그해 순서를 변경합니다. 빈 공간의 드래그 선택 박스는 사용하지 않습니다.
3. Ctrl/Shift로 여러 파일 선택 후 Delete를 누르면 목록에서 제외됩니다. 원본은 삭제하지 않습니다.
4. 도구에서 박스 또는 브러시를 선택합니다. 박스는 사각형 드래그, 브러시는 크기 조절 후 문지르기로 모자이크를 추가합니다. 브러시 한 획은 Ctrl+Z 한 번으로 취소합니다. 적용된 영역의 테두리는 표시하지 않습니다. 기존 영역의 강도를 바꾸려면 박스 도구에서 해당 위치를 클릭합니다. 영역을 클릭하고 강도(2~100)를 조절합니다. 값이 클수록 픽셀이 커집니다. 선택 영역 삭제, 원본 비교를 지원합니다.
5. 작업 저장으로 순서와 영역을 JSON에 보관합니다. 원본 파일은 같은 위치에 유지해야 합니다.
6. PNG/WEBP/JPEG를 선택하고 내보냅니다. 새 결과 폴더에 현재 순서대로 001, 002… 저장합니다. JPEG 투명 영역은 흰색으로 합성됩니다. 움직이는 WebP는 첫 프레임만 처리합니다.

## 속도
썸네일과 미리보기는 별도 작업 스레드에서 생성합니다. 최근 16장의 최대 1920px 미리보기를 메모리에 보관하고 앞뒤 이미지를 미리 읽습니다. 최초 파일 읽기는 파일 크기·디스크에 영향을 받습니다. 전체 원본은 내보낼 때 한 장씩 처리합니다.

## 메타데이터
EXIF 방향을 픽셀에 적용하고 RGBA 픽셀 바이트만으로 새 이미지를 생성합니다. EXIF, XMP, ICC, PNG 생성 파라미터 등 원본 메타데이터는 복사하지 않습니다. 출력 후 다시 열어 EXIF 및 알려진 메타데이터 키를 검사합니다. PNG/JPEG/WebP 파일 규격 자체의 필수 헤더는 존재합니다.

결과 이미지에서 제거된 원본 메타데이터를 제공하지 않는다는 의미이며, 원본·백업·작업 JSON·운영체제 임시 데이터의 보안 삭제 기능은 아닙니다. 모자이크 내용의 추측 가능성까지 방지한다는 보장은 없습니다. JSON에는 원본의 로컬 경로가 있으므로 공유하지 마세요. 이미지 픽셀에 직접 그려진 워터마크나 숨겨진 신호를 자동 제거하지 않습니다.

## 개발 / 빌드
```powershell
python -m venv .venv
.venv\Scripts\Activate.ps1
pip install -r requirements.txt
python main.py
python -m unittest -v test_photo
python -m PyInstaller --noconfirm --windowed --onedir --name Photo --icon assets/photo.ico --add-data "assets;assets" main.py
```
GitHub Actions에서 수동 실행하거나 v로 시작하는 태그를 push하면 Windows 빌드 artifact를 만듭니다. 이미지 및 작업 JSON, 빌드 출력은 소스 저장소에 올리지 않습니다.

Qt/PySide6 및 Pillow 등 의존성의 라이선스는 각 배포 라이선스를 따릅니다.

## 강도 일괄 변경
썸네일에서 Ctrl/Shift로 여러 장 또는 Ctrl+A로 전체를 선택하고 `선택 사진 강도 일괄 변경`을 누릅니다. 새 강도(2~100)를 입력하면 선택한 사진의 모든 박스·브러시 영역은 그대로 유지하고 강도만 바뀝니다. 모자이크가 없는 사진과 선택하지 않은 사진은 변경하지 않습니다. Ctrl+Z 한 번으로 일괄 변경을 취소합니다. 작업 저장 후 다시 내보내면 변경된 강도가 적용됩니다. 이미 합쳐진 결과 파일이 아니라 원본과 작업 JSON이 필요합니다.

## 처리본과 원본용 파일 동시 내보내기
내보내기에서 저장할 상위 폴더와 공통 이름(예: `a`)을 지정합니다. 입력한 이름의 폴더(예: `a`) 아래에 결과 폴더를 만듭니다. 즉 `a/a_cen`, `a/a_uncen`, 선택한 메인 그림이 있으면 `a/a_main`이 생성됩니다. 체크한 출력 종류의 하위 폴더가 이미 있으면 해당 폴더만 교체할지 `예 / 아니오`로 확인합니다. 예를 들어 메인용만 체크하면 `a/a_main`만 비우고 처리본·원본용 폴더는 그대로 유지합니다. 기본 선택과 Esc는 `아니오`이며, `예`를 눌러야 비우고 다시 출력합니다. `아니오` 또는 창 닫기는 기존 파일을 유지하고 내보내기를 취소합니다. 선택하지 않은 출력 폴더와 최상위 폴더의 다른 파일은 유지됩니다. 저장 위치의 다른 폴더는 건드리지 않습니다. 교체 대상인 하위 폴더 안에 작업 원본이 있거나 외부 연결 폴더인 경우에는 중단합니다.
- `a_cen/001.png`: 모자이크 처리본. 선택한 PNG/WebP/JPEG 형식으로 저장하고 메타데이터를 제거·검증합니다.

모든 번호는 현재 썸네일 순서이며 제외한 파일은 양쪽 모두 출력하지 않습니다. 원본 파일 자체는 수정하지 않습니다. 메타데이터 전용 제거는 EXIF 회전·ICC 정보도 제거하므로 해당 정보에 의존하던 원본용 이미지의 방향 또는 색상 표시가 달라질 수 있습니다. 모자이크 처리본은 기존처럼 EXIF 방향을 픽셀에 반영합니다.
원본용(`_uncen`)에도 자르기·비율 유지 확대·컷 합성·도장 편집을 적용하고, 모자이크만 제외합니다. 자르기 이전 단계의 모자이크도 제외합니다. 원본 확장자는 유지하며 편집이 있으면 새 픽셀로 저장하고 메타데이터를 제거합니다. 편집이 없고 모자이크만 있으면 기존처럼 원본 압축 데이터를 보존하며 메타데이터를 제거합니다.
새로 복사하는 컷에는 모자이크 없는 픽셀도 함께 보관합니다. 이전 버전에서 모자이크를 합쳐 복사한 컷이나 원본 자체에 이미 포함된 모자이크는 복원할 수 없습니다. 이전 컷은 원본용에서도 그 상태로 유지됩니다.

## 메인 게시용 그림 모으기
오른쪽 미리보기 위의 `메인 게시용으로 선택`을 체크합니다. 썸네일에는 보라색 `메인` 배지가 표시되고 작업 JSON에 선택 상태가 저장됩니다. Ctrl+Z로 체크 변경을 취소할 수 있습니다. 이전 작업 파일은 모두 미선택으로 열립니다.

내보내기 시 체크한 그림의 모자이크 처리본을 `a_main`에도 추가 저장합니다. `a_cen`, `a_uncen`은 기존처럼 전체를 저장합니다. 예를 들어 전체 중 002, 008을 체크하면 메인용 폴더에서는 `a_main/001.png`, `a_main/002.png`로 연속 번호를 새로 붙입니다. 순서를 바꾸면 현재 순서에서 메인으로 선택한 그림 순으로 001부터 다시 번호를 붙입니다. 처리본과 원본용 폴더는 전체 순서 번호를 유지합니다. `a_main`은 메타데이터가 제거된 `a_cen` 파일과 동일하며 선택한 그림이 없으면 생성하지 않습니다. 모자이크 영역이 없는 그림은 원래 보이는 상태로 메인 폴더에 출력됩니다.

## 출력 항목과 저장 위치
내보내기 옆의 `처리본`, `원본용`, `메인용` 체크박스로 출력할 폴더를 고릅니다. 체크하지 않은 폴더는 만들지 않습니다. 메인용만 선택하면 게시용으로 체크한 그림만 모읍니다.

저장할 상위 위치는 처음 한 번만 고르면 기억하며 앱을 다시 실행해도 유지합니다. 바꿀 때는 `저장 위치 변경`을 누릅니다. 폴더 이름은 내보내기 옆 입력칸에서 바로 수정합니다. 저장 위치·출력 체크·마지막 출력 이름은 PC의 앱 설정에 보관합니다. 지정한 위치가 사라진 경우에만 다시 위치를 선택합니다.

## 작업 저장 단축키
Ctrl+S는 현재 열었거나 한 번 저장한 작업 JSON에 바로 저장합니다. 새 작업의 첫 저장만 경로를 묻습니다. Ctrl+Shift+S는 다른 이름으로 저장합니다.

## 복제 도장
도구에서 `복제 도장`을 고르고 정상적인 부분을 Alt+클릭해 기준점을 지정합니다. 지울 점이나 결함 위를 드래그하면 기준점 주변 질감을 복사합니다. `브러시 크기`와 `도장 경계 부드러움`을 조절할 수 있습니다. 한 번 문지른 작업은 Ctrl+Z 한 번으로 취소합니다. 다른 그림으로 이동하면 기준점을 다시 지정합니다.

도장 작업도 작업 JSON에 저장하며 처리본·메인용·원본용에 모두 적용합니다. 도장 보정 뒤 모자이크를 적용하므로 도장으로 기존 모자이크를 덮어 없애지 않습니다. 원본 비교 버튼으로 보정 전과 비교할 수 있습니다.

## 썸네일 클릭
썸네일의 그림·파일명·주변 여백을 포함한 164×150 칸 전체를 선택 영역으로 사용합니다. 마우스를 올리면 칸 테두리가 표시되며 클릭 즉시 해당 그림을 선택합니다. Ctrl로 개별 추가/해제, Shift로 범위를 선택합니다. 선택된 여러 장을 드래그하면 함께 이동하고, 드래그하지 않고 클릭하면 한 장만 선택합니다.

## 도구 설정 기억
마지막 선택 도구, 모자이크 강도, 브러시 크기, 도장 경계 부드러움을 PC 앱 설정에 저장하고 다음 실행에서 복원합니다. 저장된 모자이크 영역을 선택해 강도를 읽어오는 동작은 기본 도구 설정을 덮어쓰지 않습니다.

## 삭제 취소와 썸네일 캐시
Ctrl+Z로 삭제를 취소할 때 살아 있는 썸네일 항목과 아이콘을 유지하고 삭제된 항목만 복원합니다. 읽어둔 썸네일은 최대 128MB 메모리 캐시에 보관하여 복원 시 디스크에서 다시 읽지 않습니다. 파일 크기나 수정 시각이 바뀐 경우에는 새로 읽습니다. 아직 읽는 중인 썸네일은 중복 작업을 만들지 않습니다.

## 닫기 전 저장 확인
저장하지 않은 작업이 있을 때 종료하거나 다른 작업을 열면 `저장 / 저장하지 않음 / 취소`를 묻습니다. 저장은 현재 작업 경로를 사용하며 첫 저장만 경로를 선택합니다. 저장 경로 선택을 취소하거나 저장에 실패하면 현재 작업을 유지하고 종료하지 않습니다.

## 여러 장을 메인으로 지정
썸네일 목록 위에 현재 선택한 장수가 표시됩니다. Ctrl/Shift 또는 Ctrl+A로 여러 장을 선택한 뒤 우클릭해 `메인으로 지정` 또는 `메인 지정 해제`를 선택합니다. 이미 선택한 그림 위에서 우클릭하면 여러 장 선택이 유지됩니다. 선택하지 않은 그림을 우클릭하면 그 그림 한 장으로 대상을 바꿉니다. 일괄 지정/해제는 Ctrl+Z 한 번으로 취소합니다.

메인 게시용 체크를 변경하면 키보드 포커스가 썸네일 목록으로 돌아갑니다. 위·아래 방향키는 화면의 윗줄/아랫줄 썸네일로 이동하며 이동한 한 장만 선택합니다. 도구 선택 콤보박스의 값은 바뀌지 않습니다.

## 그림 확대와 작업 영역
큰 미리보기에서 휠로 마우스 위치를 기준으로 25~1600% 확대/축소합니다. 가운데 버튼 드래그로 화면을 이동하고 `화면에 맞춤` 또는 가운데 버튼 더블클릭으로 초기화합니다. 확대 상태에서도 모자이크·도장 좌표는 원본 비율로 저장됩니다. 그림을 바꾸면 화면에 맞춤으로 돌아갑니다.

썸네일/미리보기 사이 분할 비율을 저장해 다음 실행에 복원합니다. 맨 왼쪽의 `저장한 작업` 패널은 상단 같은 이름 버튼으로 열고 닫으며 위치와 너비, 표시 여부를 기억합니다. 저장하거나 열었던 작업 JSON 목록을 기억하고 클릭하면 바로 불러옵니다. 현재 변경이 있으면 저장 여부를 먼저 묻습니다. 기존 작업은 `작업 파일 추가` 또는 `폴더에서 작업 찾기`로 목록에 등록할 수 있습니다. 최대 100개 작업 경로를 기억하며 작업 파일 자체는 원래 위치에 둡니다. 실행 취소는 기존처럼 Ctrl+Z를 사용합니다.

브러시 크기는 도구별로 따로 기억합니다. 모자이크 브러시와 복제 도장을 전환하면 각각 마지막 크기가 복원되며 앱을 다시 실행해도 유지합니다. 이전 버전의 공통 크기는 처음에 각 도구의 기본값으로 이어받습니다.

도구 선택은 드롭다운 대신 박스·브러시·도장 아이콘 버튼을 사용합니다. 선택된 아이콘은 파란 배경으로 표시되고 마우스를 올리면 도구 이름이 나타납니다. 아이콘 선택 후 키보드 포커스는 썸네일로 돌아가며 도구별 브러시 크기 기억은 유지됩니다.

## 다시 실행
상단 `다시 실행` 버튼, Ctrl+Y 또는 Ctrl+Shift+Z로 취소한 작업을 다시 적용합니다. 모자이크·도장·메인 지정·순서 변경·목록 제외를 지원합니다. 취소한 상태에서 새 작업을 하면 다시 실행 목록은 초기화됩니다. 다른 작업 파일을 열면 실행 취소/다시 실행 기록은 새로 시작합니다.

## 도장 반응 속도와 Ctrl 화면 이동
도장 처리는 획 주변 영역만 계산하며, 이전 획의 결과를 캐시합니다. 현재 획도 새로 문지른 영역만 갱신하고 마우스 이동 이벤트는 약 16ms 단위로 합쳐 표시합니다. 최종 내보내기도 획 주변 영역을 처리합니다. 미리보기와 최종 결과의 경계 일치 검사를 포함합니다.

확대한 화면은 Ctrl+왼쪽 드래그로 이동할 수 있습니다. 가운데 버튼 드래그도 계속 지원합니다. 화면 이동 중에는 박스·모자이크 브러시·도장이 추가되지 않습니다.

큰 그림과 아래 도구 영역 사이의 가로 조절선을 위아래로 드래그해 높이 비율을 바꿀 수 있습니다. 아래 영역이 작아지면 도구는 스크롤해서 접근할 수 있으며 높이 비율도 재실행 후 복원합니다.

## 외부 파일 끼워 넣기
탐색기에서 파일을 썸네일 목록으로 끌면 기존 순서 변경과 같은 주황색 삽입선이 표시됩니다. 놓은 위치에 여러 파일을 전달된 순서대로 묶어서 삽입하고 삽입한 그림들을 선택합니다. 이미 목록에 있는 파일은 중복 추가하지 않습니다. 원본 파일은 이동하거나 삭제하지 않습니다. 폴더를 놓으면 지원되는 내부 이미지를 같은 위치에 삽입합니다. Ctrl+Z 한 번으로 추가 전체를 취소하고 다시 실행할 수 있습니다.

## 취소 기록과 모자이크 초기화
실행 취소/다시 실행은 최대 1,000단계를 기억합니다. 변경하지 않은 그림 데이터는 기록 간에 공유해 불필요한 메모리 복제를 줄입니다. 도구 선택·브러시 크기·도장 부드러움 등 설정 변경과 값을 바꾸지 않은 슬라이더 클릭은 취소 기록에 들어가지 않습니다. 이미 적용한 모자이크의 실제 강도 변경은 그림 편집으로 기록하며 한 번 드래그한 강도 변경은 한 단계로 묶습니다.

`모자이크 초기화` 버튼에서 현재 그림, 선택한 그림, 모든 그림 중 범위를 골라 박스·브러시 모자이크를 전부 제거할 수 있습니다. 도장 보정과 메인 표시는 유지합니다. 초기화는 Ctrl+Z로 복원할 수 있습니다.

## 겹침 없는 모자이크 처리
기존 `.photo.json` 작업의 모자이크 좌표·브러시 경로·크기·강도를 그대로 읽어 개선된 렌더러로 미리보기와 내보내기를 처리합니다. 다시 칠하거나 별도로 변환할 필요가 없습니다. 기존에 내보낸 파일은 다시 내보내야 갱신됩니다.

모자이크는 도장 보정이 끝난 원본을 기준으로 이미지에 고정된 격자에서 계산합니다. 같은 강도의 마스크는 합친 뒤 한 번만 적용하므로 같은 곳을 반복해서 문질러도 더 뭉개지지 않습니다. 다른 강도가 겹치면 큰 모자이크 칸을 우선하며, 약하게 덧칠해 기존 처리를 약화시키지 않습니다. 브러시의 기존 범위는 완전히 처리한 채 바깥 경계에만 아주 좁은 부드러움을 추가합니다. 획별 강도 변경과 실행 취소는 계속 지원합니다.

## 컷 편집과 그림 합성
대상 썸네일을 선택하고 메인의 `컷 편집 모드`로 전환합니다. 별도 창을 열지 않고 같은 작업 영역에서 편집합니다. 왼쪽 썸네일에서 가져올 그림을 선택하고, 큰 원본 화면에서 필요한 부분을 사각형으로 드래그합니다. 흰 모서리/변으로 선택 범위를 조절하고 안쪽을 드래그해 옮깁니다. Shift+드래그는 새 영역 선택, `전체 선택`은 선택 해제입니다. 원본 미리보기는 휠로 확대하고 Ctrl+드래그/가운데 버튼으로 이동하며, 실제 복사는 미리보기가 아닌 모자이크·도장·기존 합성을 포함한 전체 해상도 픽셀에서 처리합니다. 번호/파일명 검색으로 원본을 찾을 수 있습니다.

오른쪽에서 `컷 그리기`를 선택해 원하는 위치와 크기로 드래그한 후 `선택 부분 붙여넣기` 또는 Ctrl+V를 누릅니다. `컷 이동`은 컷 자체를 옮기고, 흰 모서리/변은 컷 크기를 바꿉니다. `그림 위치`에서는 컷 안의 그림을 드래그하며 휠이나 +/-로 확대·축소합니다. 컷 바깥은 자동으로 잘립니다. `그림 전체 보이게`는 여백을 두고 전체를 보여주며 `컷에 꽉 채우기`는 비율을 유지해 칸을 채웁니다. 자유 배치한 컷은 겹칠 수 있고, 나중 컷이 위에 놓입니다. `더 보기`에서 앞으로 가져오기·컷 삭제·그림 비우기·기존 가로/세로 분할을 사용할 수 있습니다.

컷 모드의 `선택 부분 전체로 늘리기`는 왼쪽 선택 영역 전체를 대상 가로×세로에 맞춰 늘립니다. 비율이 달라도 선택한 부분을 추가로 자르지 않습니다. 한 사진의 위아래를 버리고 남은 부분을 원래 크기로 늘리려면 아래의 별도 `사진 자르기` 모드를 사용합니다.

컷 사이 흰 간격/자유 컷 테두리는 출력 픽셀 단위로 지정합니다. 파란색/주황색 선택 표시와 흰 조절점은 출력되지 않습니다. 컷 모드에서는 Ctrl+Z/Ctrl+Y와 메인의 취소/다시 실행 버튼도 현재 컷 편집에 적용되며, 이동/크기 변경 한 번은 취소 한 단계입니다. `모자이크 모드로` 전환하면 편집을 반영하며, 그 후에는 메인 실행 취소에서 컷 편집 묶음을 되돌릴 수 있습니다. `편집 취소`는 저장/내보내기 등에 아직 반영하지 않은 배치 변경을 버립니다. 컷 모드에서 Ctrl+S나 내보내기를 눌러도 현재 편집 내용이 포함됩니다. 기존 컷 편집 작업도 그대로 열어 조절할 수 있습니다.

붙여넣은 후 방향키로 출력 기준 1px, Shift+방향키로 10px씩 미세 이동합니다. `컷 이동`은 컷 자체를, `그림 위치`는 컷 안의 그림만 옮깁니다. 검은선/흰 간격 숫자는 입력하거나 버튼으로 조절하면 즉시 미리보기에 반영되며, 숫자 입력 후 Enter는 편집을 끝내지 않고 그림에 포커스를 돌려줍니다. `완성본 보기`는 선택 조절선을 숨기고 `원본 접기`는 결과 그림 영역을 넓힙니다.

원본 이미지는 수정하지 않습니다. 붙인 그림의 픽셀과 각 컷의 위치·배율을 작업 JSON에 함께 저장하므로 원본 복사 대상 파일을 옮겨도 붙인 그림이 유지됩니다. 그만큼 합성한 작업 파일 크기는 늘어납니다. 처리본·메인용·원본용 내보내기 모두 합성을 포함하며 원본용에서는 모자이크만 제외합니다. 대상 그림의 모자이크는 합성 후 마지막에 적용되어 붙인 그림 위에도 작동합니다.

## 시작 시 이전 작업과 새 작업
앱을 실행하면 마지막으로 저장하거나 연 작업을 자동으로 불러옵니다. 종료 직전의 선택 썸네일과 스크롤 위치도 복원합니다. 이전 버전에서 처음 업데이트하면 저장한 작업 목록의 가장 최근 작업을 사용하며, 이후 목록에 다른 파일을 추가해도 실제로 사용 중인 작업을 기억합니다. 이전 작업 파일이 이동된 경우에는 상태 안내를 표시하므로 작업 열기로 다시 지정하면 됩니다.

상단 `새 작업` 버튼은 현재 작업을 비우고 빈 작업을 시작합니다. 변경 사항이 있으면 저장/저장하지 않음/취소를 먼저 묻습니다. 새 작업을 저장하지 않고 닫으면 다음 실행도 빈 작업이며, 기존에 저장한 작업 파일은 지우지 않습니다.

컷 편집 아래의 `선택 컷 검은선 px`에서 해당 컷의 검은 테두리 두께를 지정합니다. 0은 없음이며, 컷마다 다르게 설정할 수 있습니다. 흰 간격이 있으면 흰 영역 안쪽에 검은선을 그립니다. 설정은 작업 저장과 내보내기에 포함되고 실행 취소도 지원합니다.

## 상단 숫자 도구 설정
브러시 크기·모자이크 강도·도장 경계 부드러움은 하단 슬라이더 대신 상단 숫자 입력으로 조절합니다. 숫자를 직접 입력하거나 마우스를 올려 휠로 1씩 바꿀 수 있습니다. Enter를 누르면 그림 목록으로 돌아갑니다. 도구별 브러시 크기와 마지막 도구 설정 기억은 유지하며 크기/도구 변경은 이미지 실행 취소에 포함하지 않습니다. 적용한 영역의 강도는 숫자를 입력하고 Enter로 확정하면 한 번의 편집으로 반영됩니다.

## 메인 그림만 보기
썸네일 위의 `메인만 보기`를 켜면 메인으로 지정한 그림만 기존 순서대로 표시합니다. 체크를 풀면 전체 그림이 원래 순서대로 나타납니다. 이 기능은 보기 필터이며 실제 순서·파일명·내보내기 대상을 바꾸지 않습니다. 방향키 이동과 Ctrl/Shift 선택은 표시된 그림을 기준으로 동작합니다. 필터 중 메인 지정을 해제하면 즉시 목록에서 숨겨지고, 실행 취소로 다시 표시할 수 있습니다.

## 상단 공간 압축
상단 도구/내보내기 영역을 넓은 창에서는 두 줄로 묶고, 좁은 창에서는 겹치지 않도록 세 줄로 배치합니다. 별도 모드 안내 줄을 없애고 간격을 줄여 그림/썸네일 영역에 더 많은 높이를 제공합니다. 저장 위치는 파일 버튼 줄 오른쪽에 표시합니다.

## 사진 자르기 → 비율 유지 확대
썸네일에서 사진을 고르고 상단 `사진 자르기`를 누릅니다. 큰 그림에서 남길 부분을 드래그하거나, 위/아래/왼쪽/오른쪽에서 버릴 픽셀 수를 입력합니다. `확대 결과 보기`를 켜고 결과 그림을 드래그해서 구도를 조절한 뒤 `비율 유지 확대 적용`을 누릅니다. `구도 중앙`으로 가운데 정렬할 수 있습니다.

예를 들어 1000×1500 사진에서 위아래를 버려 1000×1200만 남기면, 가로/세로를 같은 배율로 확대해 1250×1500으로 만들고 좌우에서 총 250픽셀을 잘라 원래 출력 크기 1000×1500을 채웁니다. 그림 비율이 유지되어 찌그러지지 않으며 흰 여백도 넣지 않습니다. 넘치는 방향의 구도를 드래그로 바꿀 수 있고 빈 곳이 생기는 위치까지는 이동하지 않습니다. 휠과 Ctrl/가운데 버튼 이동은 화면 확인용 확대·이동입니다.

원본 파일은 수정하지 않습니다. 자르기는 작업 저장·처리본/메인용 내보내기에 반영되고 Ctrl+Z로 취소할 수 있습니다. 자르기 전의 모자이크·도장·합성도 함께 잘려 늘어납니다. 이전 모자이크 데이터는 작업 내부에 보존하여 자른 뒤에도 강도 일괄 변경과 모자이크 초기화를 지원합니다. 원본용 출력에도 자르기와 확대를 반영하며 모자이크만 제외합니다.

이전 버전의 늘리기 결과는 자동 변경하지 않습니다. 자른 후 다른 편집을 추가하지 않은 사진은 다시 자르기를 열면 마지막 자르기 전 원본과 선택 범위를 불러오므로, 다시 자를 필요 없이 비율 유지 방식으로 재적용하거나 구도를 조절할 수 있습니다.

## 작업별 출력 폴더 이름
상단의 출력 `폴더 이름`은 공통 설정 대신 각 `.photo.json` 작업 파일에 저장합니다. 작업을 열면 해당 작업의 이름을 복원하며 다른 이름으로 저장한 작업도 이후 각각 관리합니다. 이름을 수정하면 작업이 변경된 것으로 표시되어 저장 여부를 묻습니다. 새 작업과 이름 정보가 없는 이전 작업의 초기값은 `a`이므로, 기존 작업은 원하는 이름을 한 번 지정해 저장하세요.

## 작업 이름 변경
상단 `작업 이름 변경`은 현재 `.photo.json` 파일을 같은 폴더에서 새 이름으로 바꿉니다. 현재 변경 사항을 저장한 후 이름을 바꾸며, 저장한 작업 목록과 다음 실행 때 불러올 경로도 갱신합니다. 같은 이름의 다른 파일은 덮어쓰지 않습니다. 작업별 출력 폴더 이름은 유지합니다. 아직 저장하지 않은 작업도 이름을 정할 수 있으며 첫 저장 때 해당 이름을 기본값으로 사용합니다.

저장한 작업 목록은 이름순으로 표시하고 제목 옆에 마지막 저장 시각을 표시합니다. 목록에 등록하거나 열기만 해서는 이 시각이 바뀌지 않습니다.

창 위치·크기·최대화 상태를 저장하고 다음 실행에 복원합니다. 최소화 후 복원할 때도 최소화 직전의 창 배치를 유지하며, 최소화 상태로 종료해도 다음 실행에서 정상 창으로 열립니다. 연결이 해제된 모니터의 저장 위치는 Qt가 사용 가능한 화면 안으로 보정합니다.

컷 편집에서 `자유선`으로 문질러 검은 선을 그리거나 `직선`으로 시작점부터 끝점까지 드래그합니다. `선 굵기 px`는 새 선에 적용하며 크기 변경 자체는 실행 취소에 포함하지 않습니다. 한 번 그은 선은 실행 취소 한 번으로 지우고 다시 실행으로 복원합니다. `마지막 선 삭제`도 지원하며 선은 작업 파일과 모든 편집 출력에 포함됩니다.


## MEGA 암호 압축과 공유 TXT
`MEGA로 공유`는 이미 내보낸 현재 작업의 `_uncen` 폴더를 처리합니다. 해당 폴더가 없으면 폴더를 선택합니다. 변경한 편집을 반영하려면 원본용을 먼저 다시 내보내세요.
- 공식 MEGAcmd를 설치한 뒤 버튼 메뉴의 `MEGA 연결 설정`에서 로그인 창을 엽니다. `login`을 입력하고 공식 창에서 로그인합니다. Photo는 계정 비밀번호를 받거나 저장하지 않고 공식 로그인 세션을 사용합니다.
- 암호 ZIP은 AES-256, 비밀번호는 영문 대소문자·숫자 20자리 난수입니다. 이미지의 중복 압축 비용을 줄이기 위해 ZIP 내부는 무압축으로 보관합니다. AES ZIP을 지원하는 압축 프로그램으로 해제합니다.
- 예: `05_risa/05_risa_uncen` → `05_risa/05_risa_261023.zip` → MEGA `/PhotoExports/고유번호`에 업로드 → `05_risa/05_risa_261023.txt`. 날짜는 실행 시점의 한국 날짜입니다. 같은 날짜 이름이 있으면 `_2`, `_3`을 붙여 기존 파일을 보존합니다.
- TXT 내용은 `Download Link :`, 공유 URL, 빈 줄, `Password :`, 압축 비밀번호 순서입니다. MEGA 링크의 암호가 아니라 ZIP 압축 비밀번호입니다. TXT는 업로드하지 않고 로컬에 보관합니다.
- 실패하면 ZIP과 `.upload.json`을 보존합니다. `실패한 업로드 재시도`에서 해당 JSON을 선택하면 같은 압축 파일과 비밀번호를 사용합니다. 이 JSON에도 압축 비밀번호가 들어 있으므로 공유할 때에는 TXT 또는 ZIP만 선택하세요.
- 로그인·압축·업로드는 작업 스레드에서 실행하며, 완료 전에는 앱 종료와 다른 내보내기를 막습니다. 업로드 취소 버튼은 현재 지원하지 않습니다. 업로드가 끝나면 링크 TXT 생성 결과를 알립니다.
공식 동작 참고: https://github.com/meganz/MEGAcmd/blob/master/UserGuide.md 및 https://github.com/danifus/pyzipper

내보내기 옆 `MEGA 자동 공유`는 기본 켜짐이며 마지막 선택을 기억합니다. 원본용을 체크하고 내보내면 이미지 저장이 모두 성공한 직후 암호 압축 → 업로드 → TXT 생성까지 이어집니다. 중간 확인 창 없이 최종 결과 한 번만 표시합니다. 원본용을 체크하지 않거나 출력 오류가 있으면 자동 업로드하지 않습니다. 자동 공유를 해제하면 이미지 파일만 내보냅니다.

## 배너 영역 별도 출력
썸네일에서 그림을 선택하고 상단 `배너 영역 선택`을 누릅니다. 드래그로 필요한 부분을 선택하고 모서리로 조절한 뒤 `배너로 지정`을 누릅니다. 내보내기 옆 `배너` 체크가 켜지며 `05_risa/05_risa_banner.png`로 출력합니다. 배너는 원본 해상도의 선택 부분을 그대로 자르며 편집·모자이크를 반영하고 메타데이터를 제거합니다. 작업당 하나의 배너를 지정할 수 있고, 영역·대상 그림은 작업 파일에 저장됩니다. 지정은 실행 취소/다시 실행을 지원합니다. 배너만 체크해서 출력할 수도 있습니다. 기존 배너가 있으면 다른 선택 출력과 함께 교체를 확인하며, 체크하지 않은 출력 폴더와 ZIP·TXT는 유지합니다.

배너 선택창의 `문구 넣기`를 켜면 기본 문구 `全 {count}枚`와 `{count} images`를 넣습니다. `{count}`는 현재 작업에 남아 있는 전체 그림 수로 내보낼 때 계산합니다(메인만 보기 필터와 무관). 문구 두 줄, Yu Gothic Bold/Meiryo Bold, 글자 크기 비율, 배치 위치를 조절할 수 있습니다. `출력 미리보기` 탭에서 확인하며 설정은 배너와 함께 작업에 저장됩니다. 문구는 흰색 글자·어두운 테두리·그림자로 표시하고, 선택 영역에 비해 크면 자동으로 줄여 맞춥니다. 빈 줄은 출력하지 않으며 문구 넣기를 끄면 그림만 출력합니다. 이전 버전의 문구 없는 배너는 그대로 유지되고 영역 선택창에서 다시 지정하면 문구를 추가할 수 있습니다.
